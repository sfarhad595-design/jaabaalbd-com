## ছবির সংখ্যা → Layout

### ১টা ছবি (Hero Shot)
- সবচেয়ে বেশি ব্যবহার
- মডেল full frame, center বা slight left
- টেক্সট নিচে বা ডান পাশে
- Best for: নতুন product launch

### ২টা ছবি
- সামনে + পেছনে (fabric দেখাতে)
- অথবা ২ রঙ পাশাপাশি
- একটা বড়, একটা ছোট — same frame
- Best for: "Available in X colors"

### ৩-৪টা ছবি (Collage/Detail)
- Main large photo + 2-3 small detail shots
- Polaroid / grid style
- Detail: collar, sleeve, fabric texture
- Best for: Premium product, detail দেখানো

### ৫টা ছবি (Color Range)
- সব মডেল line-up, same pose
- Background flat, solid color
- Best for: "৫ রঙে পাওয়া যাচ্ছে"

## Font Style Guide

### পণ্যের নাম (Product Name)
- **English**: Italic serif/script — যেমন: *Meher*, *Zara*, *Sophia*, *Enaya*
- মোটা না, elegant হবে
- Example font: Cormorant Italic, Playfair Display Italic

### বাংলা Caption / Tagline
- **Bold, modern** — মিক্স সাইজ
- বড় শব্দ → বড় সাইজ, ছোট শব্দ → ছোট সাইজ
- Example: "সরলতার মাঝেও থাকে **রাজকীয় সৌন্দর্য**"

### হাতের লেখা style (Casual Posts)
- Monogram launch, fun posts-এ
- "Monogram 2.0 is here!" type

## Text Placement Rules

| Element | Position |
|---|---|
| Brand logo | Top-left corner |
| Product name | Center-bottom বা center |
| Bangla tagline | Bottom 30% of image |
| "Made in Bangladesh" | Bottom-right |
| "ORDER NOW" | Bottom-right, arrow সহ |
| Background decorative text | Large, faded, behind model |

**গুরুত্বপূর্ণ:** টেক্সট মডেলের মুখের উপর দেবে না।

---

## Color Contrast Rules

| Background | টেক্সট রঙ | Accent |
|---|---|---|
| Light (cream, pink, white) | Dark (#1A1A1A) বা brand ink | Gold বা maroon |
| Dark (navy, maroon, gray) | White (#FFFFFF) | Yellow-green বা gold |
| Medium neutral (beige, brown) | White + 1 accent color | Yellow, red, বা green |

**Accent রঙ:** সর্বোচ্চ ১টা accent ব্যবহার করবে। বেশি হলে cluttered দেখায়।

3. **Dark background + White/Gold text** → Offer/special post
